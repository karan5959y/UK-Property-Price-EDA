# UK Property Price Analysis – EDA

## Project Overview
Exploratory Data Analysis of UK property transaction data using Python.

## Dataset
The dataset contains UK property transactions from 2019 with information about:
- Property price
- Transaction date
- Property type
- Postcode
- Tenure
- Location
- Property status

## Analysis Performed
- Data inspection and understanding
- Missing value analysis
- Duplicate value analysis
- Data type checking and conversion
- Descriptive statistical analysis
- Price distribution analysis
- Identification of potential anomalies/outliers
- Categorical and numerical data analysis
- Data visualization

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
